# .NET

Пример приложения [.NET](https://dotnet.microsoft.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8080` |
| Путь проверки состояния | `/` |

Railpack видит проект .NET: ставит SDK по `TargetFramework` (`net10.0`), собирает приложение
(`dotnet publish`) и запускает его на порту из переменной окружения `PORT` — её передаёт
платформа.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск в режиме разработки с отслеживанием изменений
dotnet watch

# сборка и запуск приложения
dotnet run
```

Нужен .NET SDK 10 или новее.
